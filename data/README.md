# Datos

* **`raw/`** — archivos originales de [IEEE-CIS Fraud Detection (Kaggle)](https://www.kaggle.com/c/ieee-fraud-detection/data): `train_transaction.csv` y `train_identity.csv`. No se suben al repositorio (pesan varios GB) — cada integrante debe descargarlos con su propia cuenta de Kaggle y colocarlos aquí.
* **`processed/`** — datasets intermedios generados por los notebooks (features temporales, splits train/val/test). Tampoco se versionan; se regeneran corriendo los notebooks en orden.
