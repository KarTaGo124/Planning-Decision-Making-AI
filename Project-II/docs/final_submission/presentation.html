1. Definición del Problema

El Problema: Fricción y Falta de Control en Retratos Profesionales

Superando las limitaciones de la IA convencional frente a las necesidades reales

Barrera del Usuario

📸 El Dilema del Profesional Moderno

Tomarse una fotografía ejecutiva de calidad en un estudio fotográfico involucra altos costos económicos, tiempo y logística. Para estudiantes y profesionales que inician o migran de empleo, esto representa una barrera directa de empleabilidad.

Por otro lado, usar generadores comerciales de IA sin control suele producir imágenes impersonales, deformidades faciales anatómicas o estilos inapropiados para la red de destino.

Solución Propuesta

🎯 Asistente Human-in-the-Loop

Desarrollamos una interfaz intuitiva donde el usuario sube un selfie cotidiano y el sistema genera entre 5 y 7 alternativas adaptadas al código visual de cada plataforma (LinkedIn, WhatsApp empresarial, GitHub).

  • Control biométrico: Preserva los rasgos faciales con ControlNet.
  • Decisión humana: Evaluación con botones Aceptar/Rechazar.
  • Agente LLM: Razonamiento y explicación de las preferencias del usuario.
2. Arquitectura General

Flujo Integral del Sistema Human-in-the-Loop

Integración de preprocesamiento, motor generativo, interfaz y agente explicador

Paso 1

Entrada & Filtro Ético

Carga de retrato base y validación de seguridad léxica/semántica contra términos no profesionales.

Paso 2

ControlNet Canny

Detección y centrado facial con Haar Cascade + extracción de bordes estructurales 512x512.

Paso 3

Síntesis Generativa

Generación de 5 a 7 variaciones con presets de red social y modulación de iluminación y traje.

Paso 4

Feedback & Explicación

Captura en user_decisions.json y análisis analítico de patrones mediante agente LLM.

🔄 Ciclo Cerrado de Decisión (Human-in-the-Loop)

El usuario tiene el control final sobre los resultados. El sistema no impone una imagen: registra la elección humana estructurada (Aceptar/Rechazar, calificación 1-5, notas) y traduce esos datos en explicaciones fundamentadas para iteraciones futuras.

3. Motor Generativo

Implementación Técnica: Nivel Intermedio y Básico

Cumplimiento del requerimiento de doble enfoque para tolerancia a fallos

Enfoque Principal · Nivel Intermedio

🧠 ControlNet Canny + img2img

Utiliza la arquitectura de difusión estable condicionada por bordes para preservar al 100% la estructura anatómica facial (ojos, nariz, mandíbula) mientras reemplaza la ropa y el fondo.

  • Extractor: OpenCV Canny con umbrales adaptativos (100, 200).
  • Guidance Scale: 7.0 a 8.0 para fidelidad al estilo profesional.
  • Denoising Strength: 0.40 a 0.48 para equilibrar identidad y nuevo estilo.
  • Backend: Servidor FastAPI en GPU T4 (Google Colab / MV).
Enfoque de Respaldo · Nivel Básico

⚡ Difusión Directa / Simulación Local

Mecanismo de contingencia para entornos sin aceleración por GPU dedicada. Permite ejecutar la demo de forma fluida e instantánea en cualquier laptop.

  • Segmentación por profundidad: Desenfoque bokeh de lente 85mm.
  • Colorimetría corporativa: Temperatura de color y contraste selectivo.
  • Estilización de solapa/traje: Composición visual orientada a cada red.
  • API Cloud: Compatibilidad directa con endpoints Hugging Face.

5. Seguridad y Ética

Módulo de Seguridad y Filtro Anti-Contenido Explícito

Garantizando uso responsable y bloqueo estricto de solicitudes no profesionales

Filtro Preventivo Estricto

🛡️ Validación Léxica y Semántica (`safety.py`)

Siguiendo la indicación expresa del docente, el sistema incorpora un guardarraíl ético que analiza el prompt del usuario antes de invocar cualquier modelo generativo.

  • Detección de desnudez: Expresiones regulares para variantes como "sin ropa", "sin prendas", "desnudo", "undressed", "lencería".
  • Detección de violencia / ilícitos: Bloqueo de armas, sangre o contenido de odio.
  • Insensibilidad a mayúsculas y acentos: Normalización Unicode NFKD.
Respuesta del Sistema

🚫 Notificación Formal de Bloqueo

"La solicitud fue bloqueada por infringir las directrices éticas del sistema (Categoría: Desnudez). No se permite la generación o modificación de imágenes profesionales con términos alusivos a 'sin ropa'."

El proceso se interrumpe inmediatamente a nivel de servidor, protegiendo los recursos computacionales y la integridad ética del sistema.

6. Interfaz de Usuario

Experiencia de Usuario en Streamlit: Human-in-the-Loop

Diseñada para una interacción transparente, rápida y sin fricción

1. Estado Claro

Cada variación generada inicia en estado explícito ⏳ Decisión: PENDIENTE, guiando al usuario a emitir su voto sin ambigüedades.

2. Voto Binario + Rating

Botones directos Aceptar (verde) y Rechazar (rojo) junto a slider de satisfacción 1-5 estrellas y caja de notas cualitativas.

3. Persistencia Inmediata

Cada clic actualiza en tiempo real el archivo user_decisions.json, garantizando trazabilidad y descarga con un solo botón.

7. Explicabilidad

Agente Explicador de Decisiones mediante LLM

Traduciendo datos de interacción en razonamiento fundamentado en lenguaje natural

Arquitectura Multimodelo

🤖 Comparativa de Modelos de Lenguaje

El sistema permite alternar entre tres motores para comparar la calidad de las explicaciones generadas:

  • Agente Analítico Grupo 7 (Experto Local): Motor determinista basado en reglas y agregación bayesiana. 100% autónomo y offline sin depender de APIs.
  • Google Gemini 1.5 Flash: Inferencia fluida con razonamiento conceptual avanzado.
  • OpenAI GPT-4o-mini: Síntesis analítica comparativa de patrones de elección.
Salida Estructurada y Factual

📑 Contenido del Informe Explicativo

  • Resumen Ejecutivo: Tasa global de aprobación y plataforma dominante.
  • Factores de Elección: Atributos que motivaron la aceptación (ej. preferencia por iluminación cálida y sacos oscuros).
  • Razones de Descarte: Análisis de las fotos rechazadas (ej. exceso de informalidad para perfiles corporativos).
  • Recomendaciones: Sugerencias de prompts para iterar con éxito.
  • Fidelidad Factual: Puntuación de verificación contra el JSON (98% - 100%).
